# Phase 2 — Understanding Vectors

This phase focuses on understanding the fundamentals of vectors and their role in AI, embeddings, and vector search.

## Topics Covered

1. What is a Vector?
2. Dimensions
3. Vector Representation
4. Embeddings
5. Vector Space
6. Similarity vs Distance

## Learning Objective

The goal of this phase is to understand how information can be represented numerically using vectors and why vectors are important for similarity search and semantic search.

## Key Concepts

### Vector

A vector is an ordered collection of numerical values used to represent information.

Example:

```text
[0.2, 0.5, 0.8]
```

### Dimensions

The number of values in a vector represents its number of dimensions.

```text
[10, 20, 30]
```

This is a 3-dimensional vector.

### Embeddings

An embedding is a numerical representation of data generated by an embedding model.

Basic workflow:

```text
Text
  ↓
Embedding Model
  ↓
Embedding (Vector)
```

### Vector Space

A vector can be viewed as a point in a mathematical space. Similar vectors can be compared using distance or similarity measures.

### Similarity vs Distance

Distance measures how far apart two vectors are.

Similarity measures how closely two vectors are related.

Generally:

```text
Smaller Distance  → More Similar
Higher Similarity → More Similar
```
